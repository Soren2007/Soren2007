## 🧑‍💻 About Me

Hello! I'm **Soren Shamlou**, a passionate Backend Developer with a strong interest in software engineering, system architecture, and cybersecurity.

My journey in technology started with electronics and hardware programming, particularly C and embedded systems. I achieved **1st Place in a Line-Following Robot Competition**, which strengthened my problem-solving and engineering skills.

Today, my primary focus is Backend Development, especially building scalable, maintainable, and secure applications using Python and Django.

### 🚀 What I Do

- 🐍 Backend Development with Python & Django
- ⚙️ RESTful API Design and Development
- 🗄️ Database Design and Optimization
- 🔄 Asynchronous Processing with Celery & Redis
- 🐧 Linux Administration and Server Management
- 🔐 Cybersecurity and Penetration Testing
- 🛠️ Software Architecture and System Design

I enjoy exploring complex technical challenges, learning new technologies, and turning ideas into practical software solutions.
